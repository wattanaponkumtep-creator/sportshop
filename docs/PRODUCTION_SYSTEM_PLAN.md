# แบบแปลนปรับปรุงระบบ: รับงาน → ผลิต → ส่ง (PUA SPORT SATTAHIP)

> สรุปจากการประชุม — ใช้เป็นคู่มืออ้างอิงตอนสร้างจริง

## บริบท & ปัญหา
- แฟรนไชส์แบรนด์ **PUA SPORT** (สาขาสัตหีบ) → ผูกสัญญาใช้โรงงานเดียว (กระจายโรงงานไม่ได้)
- ปัญหา: **ช้า + ของเสีย** โดยเฉพาะงาน 100+ ตัว → ชื่อเสียงเสี่ยง
- ไพ่ต่อรอง: แบรนด์เดียวกัน = ชื่อเสียงเดียวกัน (กดดันโรงงานได้) + รวมพลังสาขาอื่น
- หัวใจ: สร้าง "ด่านตรวจของเราเอง" → ลูกค้าไม่มีวันเห็นของเสีย

## เส้นทางมาตรฐาน (pipeline)
1. รับงาน + ออกแบบ *(มี)*
2. ลูกค้ายืนยันแบบ mockup *(มี)*
3. ลูกค้าส่งจำนวน (ผ่านฟอร์มกรอกเอง)
4. เลือกสเปค (selector)
5. แจ้งวันเสร็จ (เทียบ "วันที่ต้องใช้" ว่าทันไหม)
6. ใบงานสรุป (รูปนำ)
7. เก็บมัดจำ *(มี)*
8. รีเช็ค/ยืนยันกับลูกค้า + ข้อตกลงความรับผิดชอบ
9. ส่งโรงงาน (รูป+ไฟล์+ข้อความ+"ทำตัวอย่างก่อน")
10. โรงงานผลิต → อัปเดตสถานะผ่าน LINE
11. รับของ → เช็กความถูกต้องออเดอร์
12. ส่งลูกค้า *(มี)*

## รายการที่จะสร้าง (11 ข้อ)

### 1. ใบงานโรงงาน + ตัวอย่างก่อนผลิต
- ทุกงานทำตัวอย่าง **1 ตัว** (เสื้อ) หรือ **1 ชุด** (เสื้อ+กางเกง) ก่อน → เก็บให้ลูกค้าด้วย
- ใบงานสเปคครบ **รูป mockup นำเสมอ** (โรงงานจำงานด้วยรูป ไม่ใช่รหัส)
- ส่ง **LINE + PDF**
- สเปค: ไซซ์ · สี · เบอร์-ชื่อ · สปอนเซอร์-โลโก้ · ผ้า · คอ · จำนวน · โลโก้ 3D · ปกคอ · ปลายแขน · กระเป๋า · ลายหน้า/หลัง · (กางเกง) · รูป mockup อนุมัติ
- คำสั่งเด่น: "ผลิตตัวอย่าง 1 ตัว/ชุดก่อน — รออนุมัติก่อนเต็มล็อต"

### 2. คำนวณเวลาส่ง + นโยบายงานด่วน
- สูตร: ทำตัวอย่าง+อนุมัติ + ผลิต(ตามจำนวน) + buffer + ส่ง
- quote (เผื่อแล้ว, อิงข้อมูลจริง): 1–60 ตัว = **20–22 วัน** · 61–100 = **35 วัน** · 100+ = เคสต่อเคส
- เป้าหมายถ้าได้คิว: 1–60=12–14 · 61–100=18–20 · 100+=25
- ข้อมูลจริง: โรงงานผลิต 100 ตัว ~10 วัน แต่ turnaround จริง ~27 วัน (จมคิว ~17 วัน) · ความแกว่งสูง (1.3–51.9 วัน)
- หลักคิด: บอกลูกค้ายาวกว่าจริงเสมอ
- งานด่วน: รับเมื่อครบ 3 ข้อ (①โรงงานยืนยันคิว ②ค่าด่วน +20–30% ③ไม่ต่ำกว่าขั้นต่ำสุด) · *ปฏิเสธดีกว่ารับแล้วช้า* · ด่วนใช้รูปถ่ายอนุมัติแทนตัวอย่างจริง
- ช่อง "วันที่ลูกค้าต้องการใช้" → เทียบว่าทันไหม

### 3. ยืนยันจำนวน/รายละเอียด + ข้อตกลงความรับผิดชอบ
- ส่งสรุป (จำนวนรวม + แยกไซซ์ + รายชื่อ-เบอร์รายคน + ชนิด + ราคา) ให้ลูกค้า **กดยืนยัน + ติ๊กยอมรับ** → เก็บเวลาเป็นหลักฐาน
- แบ่งความรับผิดชอบชัด:
  - **เรารับผิดชอบ:** ผลิตไม่ตรงที่ยืนยัน · คุณภาพพิมพ์ · ชำรุดจากการผลิต
  - **ลูกค้ารับเอง:** ให้ชื่อ/เบอร์/ไซซ์/สเปคผิด · เปลี่ยนใจหลังยืนยัน
- (ใช้แนวเดียวกับหน้าอนุมัติ mockup ที่มี checklist+ข้อตกลงอยู่แล้ว)

### 4. เส้นทางมาตรฐาน (pipeline)
- checklist ในแต่ละ JOB → ทำครบทุกสเตปก่อนส่งโรงงาน
- เพิ่ม: ช่อง "วันที่ต้องใช้" · สเปค selector (รวบรวมตอนลงมือ แบบไล่หมวด) · คติร้าน "We pay attention to every detail" บนเอกสารลูกค้า

### 5. ฟอร์มให้ลูกค้ากรอก roster เอง
- ลิงก์ให้ลูกค้ากรอก ชื่อ-เบอร์-ไซซ์ รายคน → เข้าระบบตรง (กันเราพิมพ์ผิด + ความผิดเป็นของลูกค้าชัด)
- validation: ไซซ์ dropdown · เตือนเบอร์ซ้ำ · ช่องบังคับ
- สำรอง: เรากรอก + วาง/อัปโหลด Excel + ด่านยืนยัน (ข้อ 3) เป็นตาข่าย

### 6. ติดตามการผลิตผ่าน LINE (1 แตะ)
- ส่งงานเข้า LINE โรงงาน **รูป mockup นำ** + ปุ่มสถานะ (เริ่มผลิต/พิมพ์เสร็จ/เย็บเสร็จ/QC ผ่าน/พร้อมส่ง) → แตะแล้วเด้งเข้าระบบ
- ระบบเตือนเราเมื่องานค้างเกินกำหนด (เผื่อโรงงานไม่กด)
- สถานะไหลไปหน้า track ลูกค้า + แจ้งลูกค้าอัตโนมัติ
- เซ็ตอัป: โรงงานแอด LINE OA ร้าน (สำรอง: ลิงก์แตะหน้าเดียว)

### 7. เช็กความถูกต้องออเดอร์ตอนรับของ
- *ไม่ใช่ QC คุณภาพ (โรงงานทำแล้ว)* — เช็กว่า "ออเดอร์เราครบถูกไหม" เพราะโรงงานไม่มี roster เรา
- เทียบ roster: นับจำนวน · นับไซซ์ (L กี่ตัว ตรงสั่งไหม) · สุ่มชื่อ-เบอร์ 5–10 ตัว

### 8. Scorecard โรงงาน
- คะแนนจากข้อมูลจริง: ส่งตรงเวลา % · ของเสีย % · ช้าเฉลี่ยกี่วัน (รายเดือน)
- ใช้กดดันโรงงานด้วยตัวเลข + ตัดสินใจอนาคต
- คำนวณจากข้อมูล timeline ที่มีอยู่ได้

### 9. สั่งซ้ำ-ลูกค้าเก่า (Reorder)
- เก็บแบบ + roster เดิมของแต่ละทีม → สั่งซ้ำคลิกเดียว (แก้รายชื่อ/จำนวนได้)

### 10. กระบวนการเคลม/รับประกัน
- แจ้งเคลม → ประเมิน (ผิดเรา/ไม่ผิดเรา ตามข้อ 3) → แก้/ชดเชย → ติดตามจนจบ → เก็บประวัติ

### 11. นโยบายเสริม
- ตารางไซซ์จริง (วัดนิ้ว อก/ยาว) โชว์ตอนลูกค้าเลือกไซซ์
- หมายเหตุ "สีจออาจต่างจากสีพิมพ์" บนหน้าอนุมัติ/ยืนยัน
- เก็บเงินครบก่อนส่งของ (เสื้อ custom ขายต่อไม่ได้)

## ลำดับการสร้าง (phases)
- **Phase 1 — ฐาน + งานโรงงาน:** ฟิลด์ "วันที่ต้องใช้" + สเปค/ตัวอย่าง + ข้อ 2 (คำนวณเวลา) + ข้อ 1 (ใบงาน+ตัวอย่าง รูปนำ)
- **Phase 2 — ฝั่งลูกค้า:** ข้อ 5 (ฟอร์ม roster) + ข้อ 3 (ยืนยัน+ข้อตกลง) + ข้อ 11 (ไซซ์/สี)
- **Phase 3 — ติดตาม+โรงงาน:** ข้อ 6 (LINE สถานะ) + ข้อ 7 (เช็กรับของ) + ข้อ 8 (scorecard)
- **Phase 4 — หลังการขาย:** ข้อ 9 (reorder) + ข้อ 10 (เคลม) + ข้อ 11 (เก็บเงินครบ)
